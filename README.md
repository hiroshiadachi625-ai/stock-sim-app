# 株式投資 情報表示・仮想売買シミュレーションゲーム(個人用)

政治動向を含むニュースと値動きから「おすすめ銘柄」を表示し、「買ったつもり」ボタンで
仮想ポートフォリオに記録するだけの、実資金を一切動かさないシミュレーションアプリです。

**個人利用専用です。他人に配布・公開する場合は、投資助言業・投資運用業に関する規制への
該当性をあらためて確認してください(詳しくは別途お渡しした企画書を参照)。**

## セットアップ

Python 3.10以降を想定しています。

```bash
cd stock-sim-app
pip install -r requirements.txt
streamlit run app.py
```

ブラウザが自動で開かない場合は、ターミナルに表示される `http://localhost:8501` を開いてください。

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | Streamlit画面本体(おすすめ銘柄・ポートフォリオ・ウォッチリストの3タブ) |
| `watchlist.py` | 監視銘柄リスト(日本株・米国株、セクタータグ付き)。ここを編集して銘柄を増減できます |
| `data_fetch.py` | yfinance経由での株価取得 |
| `news_fetch.py` | RSSフィード経由でのニュース取得(NHK、Yahoo!ニュース、Reutersなど) |
| `scoring.py` | ニュースとの関連度・値動きから推奨スコアを計算するロジック(ルールベース) |
| `portfolio.py` | 仮想売買の記録・成績集計(SQLite: `portfolio.db`) |

## 動作確認について(重要)

開発環境(クラウドのサンドボックス)はネットワークが制限されており、
Yahoo FinanceやRSSフィードなど外部サイトへのアクセスができませんでした。そのため:

- **ロジック部分(スコアリング・ポートフォリオ計算)は、モックデータを使ったテストで動作確認済みです。**
- **株価取得・ニュース取得の実際の通信は、お使いのPC上で初めて実行されることになります。**
  通常のインターネット接続があれば動作するはずですが、初回実行時に接続エラーが出た場合は
  以下を確認してください。
  - `pip install -r requirements.txt` が正常に完了しているか
  - ファイアウォール等でPython/ターミナルの通信がブロックされていないか
  - yfinanceの仕様変更でエラーが出る場合は `pip install -U yfinance` で最新化

## 使い方

1. 「🔍 おすすめ銘柄」タブでスコアの高い順に銘柄が表示されます。理由(関連ニュース・値動き)も
   一緒に表示されるので、ブラックボックスにならないようにしています。
2. 気になる銘柄があれば株数を指定して「✅ 買ったつもり」を押すと、実際の資金は動かさずに
   仮想ポートフォリオへ記録されます。
3. 「💼 ポートフォリオ」タブで保有中ポジションの含み損益を確認し、「💰 売ったことにする」で
   決済(損益確定)できます。取引回数・勝率・実現損益の合計もここで確認できます。
4. 「⚙️ ウォッチリスト」タブは現在の監視銘柄一覧です。増減したい場合は `watchlist.py` の
   `DEFAULT_WATCHLIST` を直接編集してください。

## iPhoneからどこでも使えるようにする(クラウド公開)

このアプリを常時起動のサーバーに置き、iPhoneのホーム画面からアプリのように開けるようにする手順。
無料でできる **Streamlit Community Cloud** を使う方法を説明する。

### 0. 前提:このアプリは元々「個人専用」だった

クラウドに置くと、URLを知っている人なら誰でもアクセスできる状態になる。
そのため以下の対策を入れてある。

- アプリ自体に簡易パスワードロックを追加済み(`auth.py`)。`APP_PASSWORD`という
  設定(Secrets)を入れた場合のみパスワード入力画面が出る。ローカルで動かすだけなら
  この設定は不要(素通りする)。
- `portfolio.db`(仮想売買の記録)は`.gitignore`でGitHubにアップロードされないようにしてある。
- クラウド版は仕組み上、再デプロイやスリープからの復帰でポートフォリオのデータが
  消える可能性がある。「ポートフォリオ」タブ下部の「⬇️ 取引データをCSVでバックアップ」を
  ときどき押してデータを残しておくことを推奨する。

### 1. GitHubアカウントを作る

1. https://github.com/ にアクセスし、「Sign up」からアカウントを作成する(メールアドレスが必要)
2. メール認証を済ませる

### 2. コードをGitHubにアップロードする

一番簡単なのは、GitHubのWeb画面から直接アップロードする方法。

1. GitHubにログインした状態で右上の「+」→「New repository」
2. Repository name に `stock-sim-app` と入力し、**Private**(自分専用)を選んで「Create repository」
3. できたリポジトリの画面で「uploading an existing file」のリンクをクリック
4. `stock-sim-app`フォルダの中身(`app.py`など全ファイル。`.gitignore`や`.streamlit`フォルダも含む)を
   まとめてドラッグ&ドロップし、「Commit changes」

### 3. Streamlit Community Cloudでデプロイする

1. https://share.streamlit.io/ にアクセスし、GitHubアカウントでログイン
2. 「Create app」→ 先ほど作ったリポジトリ(`stock-sim-app`)を選択
3. Main file path に `app.py` を指定して「Deploy」
4. デプロイが終わると `https://xxxxx.streamlit.app` のようなURLが発行される

### 4. パスワードを設定する(Secrets)

1. デプロイしたアプリの管理画面(右下の「⋮」メニューなど)から「Settings」→「Secrets」を開く
2. 次のように入力して保存する(パスワードは好きな文字列に変更する):
   ```
   APP_PASSWORD = "好きなパスワード"
   ```
3. アプリが再起動し、以後はパスワード入力画面が出るようになる

さらに念のため、Streamlit Community Cloudの「Settings」→「Sharing」で
閲覧できるユーザーを自分のメールアドレスだけに制限する設定(Google/GitHubログインを要求する機能)も
できる場合がある。設定画面を確認してみてほしい。

### 5. iPhoneのホーム画面にアイコンを追加する

1. iPhoneのSafariで、発行されたURL(`https://xxxxx.streamlit.app`)を開く
2. パスワードを入力してログインする
3. Safari下部の共有ボタン(□に↑のアイコン)をタップ
4. 「ホーム画面に追加」を選択し、名前を確認して「追加」

これでホーム画面にアイコンが置かれ、タップするとブラウザのアドレスバーなしで
アプリのように開けるようになる(厳密にはWebアプリで、App Storeのネイティブアプリではない)。
